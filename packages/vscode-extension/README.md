# STR: SVG to React + Tailwind

Convert SVG icons into clean React and Tailwind code directly in VS Code, Cursor, Windsurf, and VSCodium.

## Features

- Automatically converts SVG pasted into JavaScript and TypeScript React files.
- Converts selected SVG text with `STR: Convert Selection`.
- Converts clipboard SVG with `STR: Convert Clipboard`.
- Keeps each conversion to a single undo step.
- Supports Tailwind mapping, TypeScript types, component style, and component name settings.

## Usage

1. Open a `.jsx`, `.tsx`, `.js`, or `.ts` file.
2. Paste an SVG, or select SVG text and run a command from the Command Palette.
3. Configure conversion behavior under `STR (SVG to React)` in VS Code settings.

For automatic paste conversion, make sure `editor.pasteAs.enabled` is enabled.
