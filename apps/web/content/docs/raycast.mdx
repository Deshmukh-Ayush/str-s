# Raycast Extension

> **Status**: Coming soon. Raycast support is planned — testing is blocked on Mac hardware access before store submission.

The STR Raycast extension allows macOS users to convert SVGs from any app or clipboard with a single keystroke.

## Planned Commands

### 1. Convert SVG from Clipboard
Reads the current SVG string from the system clipboard, runs `convert()`, copies the generated React component back to the clipboard, and triggers a confirmation toast with the component name.

### 2. Convert SVG from Selected Text
Reads highlighted text in the frontmost application window (Figma, browser DevTools, or text editor) and converts it to a React component. Falls back to clipboard content if no active selection is detected.

---

## Availability

The Raycast extension is not yet available in the Raycast Store. The code is implemented and verified locally via `ray develop` in the monorepo (`packages/raycast-extension`), but store submission is pending testing on macOS hardware.

---

## Planned Preferences

Adjust conversion options in Raycast's extension preferences:

- **Component Name**: Custom component name (default: `SvgComponent`).
- **Tailwind Mapping**: Choose between `loose`, `strict`, or `off`.
- **Component Style**: Choose between `arrow` function or `function` declaration.
- **TypeScript**: Toggle `React.SVGProps` TypeScript definitions.
